## 1. 二值问题

> 在 2026-11-03 00:00 至 2026-11-16 23:59（CST）的观测窗口内，
> 是否存在**至少 1 个集合**同时满足：成交 ≥ 20 笔、独立买家 ≥ 20、`totalSupply()` 可算、
> 扣已知成本（gas + 平台费 + royalty 未知单列）后 `netKnownCostEVPerMint > 0`？

- **是** → 该赛道存在可重复正 EV 的候选，进入 W2 小样本真钱验证（另行批准）。
- **否** → 维持 C：停止自动盈利方向，项目转入只读归档。

没有第三种答案。**"样本不足" 记为「未能判决」，同样结束本章，不再延长。**

## 4. 终止红线（提前结束本章）

任一命中即停，写结论：

```
R1  连续 7 天全市场 0 笔 Element 成交            → 数据源或市场失效
R2  probe NRestarts 增加 ≥ 3，或 release-gate 非 0 → 仪器不可信
R3  任一窗口 dataComplete=false 且缺口未补回      → 数据不可用
R4  某候选集合 top1 买家占比 ≥ 80% 且成交 ≥ 20    → 该集合剔除（对手质量恶化）
R5  私钥/钱包/下单动作被触发                      → 立即停（本不该发生）
```

## 5. 巡检节奏：默认静默 + 四条触发器 + 每日一行

不再每 2 小时播报。每小时静默检查一次，只在下列情形打扰：

```
T1  lag > 50 或 gap > 0 持续 ≥ 10 分钟
T2  NRestarts 增加，或 release-gate 出现非 0
T3  出现符合第 1 节条件的新候选集合（唯一"好消息也报"）
T4  命中 R1–R5 任一红线
```

**每日 09:05 CST 固定一行**，格式固定为：

```
[W1 D+n] 块高 131xxxxxx | 成交 xx 笔 / 集合 xx | 候选 n 个 | 最佳 netEV $x.xxxx | 红线 无
```

无变化就只发这一行，不解释、不展开。

## 6. 预注册的分析口径（防事后挑假设）

- 只用 `analysis/w0-verdict.py` 的既有字段，不新增派生指标；
- EV 分母固定为「该集合在该窗口内的全部成交」，不按价格分层；
- royalty 未知时并列 `netKnownCost` 与 `royaltyUnknown`，不做单点假设；
- 候选集合名单在窗口结束后**一次性**计算，不边跑边看；
- 结论表述禁止出现"真实需求"、"真人买家"，只能说"未发现/发现集中度信号"。
